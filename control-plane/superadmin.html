New Workspace

Manually provision a new Odoo tenant database

Tenant Details

This will create a new Odoo database and register the workspace

Provisioning Note

Creating a workspace will:

  1. Create a new PostgreSQL database named ws_<slug>
  2. Install custom Odoo addons (flipkart_os, b2b_os, robifel_hr)
  3. Set the company name and admin user credentials
  4. Register the workspace in the master registry

Requires ODOO_MASTER_PASSWORD to be set in Settings.
